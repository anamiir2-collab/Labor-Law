# قانون العمل رقم ١٤ لسنة ٢٠٢٥ — موقع ثابت

موقع ويب ثابت بالكامل لعرض **قانون العمل المصري الجديد رقم ١٤ لسنة ٢٠٢٥** والقانون المرافق له، بتصميم أندلسي (الأخضر الزمردي، الذهبي، العاجي) وواجهة RTL متجاوبة بالكامل مع جميع الأجهزة.

---

## نظرة عامة

يعرض الموقع النص الكامل لقانون العمل المصري الجديد والقانون المرافق له في 5 كتب و27 بابًا و311 مادة، مع تجربة قراءة مريحة:

- **التصميم**: هوية بصرية أندلسية/مغاربية (أخضر زمردي + ذهبي + عاجي)
- **الاتجاه**: RTL كامل ومُحسَّن للعربية
- **الخطوط**: Amiri و Noto Naskh Arabic (مع بدائل نظامية)
- **التجاوب**: متجاوب 100% من 320px حتى الشاشات الكبيرة
- **التخزين المؤقت**: يعمل بدون إنترنت بعد أول تحميل

## المزايا

- **ملف HTML نظيف** بدون JavaScript مُضمَّن (فصل كامل للاهتمامات)
- **بنية احترافية**: `assets/css` + `assets/js` + `assets/js/data`
- **بيانات منظمة**: كل ملف JSON مقروء مع مسافات بادئة بدل سطر واحد طويل
- **بدون `document.write()`**: استبدلنا بنمط تحميل متزامن صحيح عبر وسوم `<script>` مرتبة
- **تنقل كامل**: السابق/التالي/الانتقال لرقم صفحة/شريط تقدم ذهبي
- **فهرس شامل**: على الحاسوب شريط جانبي ثابت، وعلى الهاتف Drawer احترافي
- **بحث فوري**: في نص القانون + انتقال مباشر لأي مادة برقمها (يدعم الأرقام العربية والإنجليزية)
- **روابط داخلية ذكية** بين المواد المُشار إليها في النص
- **توثيق الصفحة الحالية في الرابط** (#m137) واستعادتها عند إعادة الفتح
- **متجاوب 100%** من 320px حتى الشاشات الكبيرة، بدون تمرير أفقي
- **دعم safe-area** للهواتف ذات النوتش (iPhone X+)
- **دعم prefers-reduced-motion** لتقليل الحركة للمستخدمين الذين يفضلون ذلك
- **بدون أخطاء Console، بدون مفاتيح API، بدون تتبع**

## الرفع على GitHub Pages (بدون أي إعدادات)

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات المشروع إلى جذر المستودع.
3. من **Settings → Pages** اختر: **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. خلال دقيقة سيصبح الموقع متاحًا على:
   `https://<username>.github.io/<repository-name>/`

> لا يوجد Build، لا npm، لا Node، لا Backend — المشروع يعمل كما هو.

## التشغيل المحلي

الطريقة الأبسط: افتح `index.html` مباشرة في المتصفح (يعمل ببروتوكول `file://`).

للتطوير المُوصى به، شغّل خادم HTTP بسيط:

```bash
# Python 3
python3 -m http.server 8000

# أو Node.js (بعد npm install -g http-server)
http-server -p 8000
```

ثم افتح `http://localhost:8000` في المتصفح.
